Prologue

어느 날, 뉴스에서 이런 말을 들었다.

“이대로라면 2070년에는 북극의 여름 빙하가 모두 사라질 수도 있습니다.”

정말일까? 누가, 무엇을 근거로 그렇게 말할 수 있을까?

그리고 만약 사실이라면 — 우리는 무엇을 미리 해 볼 수 있을까?

답을 찾으려면 두 가지 도구가 필요하다.

하나는 이미 일어난 일을 숫자로 읽어 내는 도구 — 데이터 분석.

다른 하나는 아직 일어나지 않은 일을 컴퓨터 속에서 먼저 해 보는 도구 — 시뮬레이션.

이제, 지난 몇 주 동안 우리가 손에 넣은 이 두 도구를 다시 꺼내 보자.

Ⅲ. 현상을 분석하는 소프트웨어

1-1 데이터의 가치

데이터는 ‘21세기의 원유’

경험·실험·관찰·측정·조사로 모은 수치, 문자, 이미지, 음성은 모두 데이터다. 하나하나는 버려지기 쉽지만 쌓이고 분석되면 몰랐던 사실을 밝히고, 합리적인 의사 결정과 미래 예측을 돕는다. 원유를 정제하면 여러 제품이 되듯, 같은 데이터도 누가 어떤 목적으로 분석하느냐에 따라 다른 정보가 된다.

2-1 시뮬레이션의 이해

시뮬레이션

현실 세계에서 일어나는 일이나 시스템을 모방하는 실험

→

시뮬레이션 프로그램

컴퓨터에서 모의 실험을 할 수 있도록 만든 프로그램
예) 운전 연습, 해수면 상승 예측

시간·공간의 한계로 확인하기 어려운 상황을 간단히 설정하고 결과를 바로 확인 → 시간과 비용을 아끼고 안전하다.

🔍

역할 ① 문제 파악

🔁

역할 ② 다양한 대안 적용

여러 상황과 요소를 간단히 바꿔 적용하고 결과를 바로 확인

🔮

역할 ③ 미래 예측

2-2 시뮬레이션 모델과 구성 요소

현실 세계 → 추상화 → 모델 → 프로그램

시뮬레이션 모델: 모의 실험의 대상을 목적에 맞게 단순화한 것. 대상이 되는 객체와 객체가 따르는 규칙을 분명히 정해야 한다.

추상화

컴퓨터가 처리할 수 있도록 복잡한 현상을 단순화

계산 가능성

수학적 알고리즘을 기반으로 프로그램에서 계산 가능

가변성

다양한 변수와 조건을 바꿀 수 있음

예) 급식실 시뮬레이션

객체: 학생, 배식대, 좌석
규칙: 배식 받기 → 자리에 앉기 → 식사하기 → 퇴식구에 정리하기

시뮬레이션 프로그램의 구성 요소

시뮬레이션 모델 + 화면 구성(어떻게 보여 줄지) + 구현 기능(규칙을 구현하는 알고리즘과 코드)

원주율 구하기 (몬테카를로)

공 튀기기 (중력)

속도 += 중력가속도 × dt, 위치 += 속도 × dt, 바닥에 닿으면 속도 방향 반대 · 0.8배

🫧

입자 운동 (랜덤워크)

(random()-0.5)*40 → -20~20만큼 무작위 이동, 경계 처리
응용: 호흡기 전염병 예방 수칙 (거리에 따른 감염 속도)
