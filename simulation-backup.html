시뮬레이션 프로그램

컴퓨터에서 모의 실험을 할 수 있도록 만든 프로그램

왜 시뮬레이션 프로그램을 쓸까? 시간·공간의 한계 때문에 확인하기 어려운 상황을 간단히 설정할 수 있고, 결과를 바로 확인할 수 있으며, 현실에서 직접 하는 것보다 시간과 비용이 적게 들고 안전합니다.

시뮬레이션 프로그램의 3가지 역할

역할 1

문제 파악

현실의 문제 상황을 프로그램에서 확인하고, 결과를 기록·누적해 경험적으로 해석

역할 2

다양한 대안 적용·확인

여러 상황이나 요소를 현실보다 간단히 바꿔 적용하고 결과를 바로 확인

역할 3

미래 예측

중력에 따라 떨어지고 튀어 오르는 공

3단계 모델 구현하기입니다. 모델 설계에서 정한 규칙이 코드의 어디에 들어 있는지 찾아보세요.

코드 읽기

ball.velocity.y = ball.velocity.y + (g*dt)v = v₀ + a·t를 코드로 쓴 것. 0.01초마다 속도가 g×0.01만큼 바뀌어요.
ball.pos = ball.pos + ball.velocity*dt0.01초 동안 이동한 거리(속도 × 시간)만큼 위치를 바꿔요.
crash = floor.pos.y + (floor.size.y/2) + ball.radius바닥의 중심 y + 바닥 두께의 절반 + 공 반지름 = 공이 바닥에 닿는 높이
ball.velocity.y = -ball.velocity.y*0.8-는 방향을 반대로(위로), 0.8은 에너지 손실로 속도가 80%로 줄어드는 것
while t < 20:시뮬레이션 시간 20초 동안 반복

위 코드에서 값을 하나씩 바꿔 실행하고, 결과를 표에 기록하세요. (기록은 이 브라우저에 저장돼요)

바꿀 값예측관찰 결과
g = -1.6 (달)
g = -24.8 (목성)
*0.8 → *1.0
*0.8 → *0.5

실험 결과 정리
  • 달(-1.6): 천천히 떨어지고 천천히 튄다. 목성(-24.8): 매우 빠르게 떨어지고 빠르게 튄다. 중력가속도가 클수록 속도가 빨리 변한다.
  • 1.0: 에너지 손실이 없어 처음 높이까지 계속 튄다. 0.5: 금방 낮아져 멈춘다.
  • 1.2: 튈수록 더 높이 올라간다 → 현실에서는 일어날 수 없는 결과! 모델 평가에서 이런 값은 잘못된 규칙임을 찾아내야 해요.

두 공을 나란히 놓고 같은 높이에서 떨어뜨려 비교하는 시뮬레이션입니다. 빈칸 ____을 채워 완성하세요.

정답 보기 
g_moon = -1.6
moon.velocity.y = moon.velocity.y + (g_moon*dt)
moon.velocity.y = -moon.velocity.y*0.8

해석 같은 높이에서 떨어뜨려도 달의 공은 훨씬 천천히 떨어져 바닥에 늦게 닿고, 튀어 오르는 움직임도 느리다. 중력가속도가 작을수록 속도가 느리게 변하기 때문이다.

원래 공 튀기기 코드에 count 변수를 만들어, 공이 바닥에 닿을 때마다 1씩 늘리고 화면 아래(scene.caption)에 표시해 보세요.

힌트 / 정답 
count = 0                                   # while 문 위에 추가
...
    if ball.pos.y < crash:
        ball.velocity.y = -ball.velocity.y*0.8
        ball.pos.y = crash
        if ball.velocity.y > 0.5:            # 거의 멈춘 공은 세지 않기

• 65세 이상 노인의 보행 속도: 1초당 약 0.85m, 지팡이 등 보조 장치를 쓰면 0.7m 이하
2단계
모델 구성
객체: 신호등, 보행자, 횡단보도
규칙: ① 신호등은 정해진 보행 시간이 지나면 신호를 바꾼다. ② 보행자는 초록불인 동안 1초당 입력한 거리만큼 이동한다.

모델 구현
VPython으로 화면(횡단보도·신호등·보행자)을 구성하고, 입력받은 신호 시간과 보행 속도로 이동을 구현

정답 확인
  • 13초, 0.85m/s → 6÷0.85 ≈ 7.1초 필요 → 건넘
  • 8초, 1m/s → 6초 필요 → 건넘

예시 보기 — 비 오는 날 우산 속도 시뮬레이션

1단계 걷는 속도에 따라 비를 얼마나 맞는지 시뮬레이션으로 확인할 수 있을까?

2단계 자료 빗방울의 낙하 속도(약 초당 수 m), 사람의 걷기·뛰기 속도(초당 약 1.4m, 3m)

2단계 객체·규칙 객체: 사람(상자), 빗방울(작은 구 여러 개) / 규칙: 빗방울은 일정한 속도로 떨어지고, 사람은 입력한 속도로 이동하며, 사람에 닿은 빗방울 수를 센다.

3단계 빗방울을 리스트로 만들고 while 반복문으로 위치를 갱신, if로 사람과의 충돌을 판별한다.

4단계 속도를 바꿔 실행한 결과를 실제 경험과 비교한다. 바람의 영향은 무시했으므로 바람을 규칙에 추가할 수 있다.
